# Quick Audio Manager validation

Cloud-only port from `main` commit `0bee37011d7b38e44661a28cbe79fda448501952`. No Quick Input feature-branch changes were included, and no user-local files were used.

## Toolchain actually exercised

- Official Godot **4.7.2 stable Mono**, build `ed1daf0bf`, Linux x86_64
- Microsoft .NET SDK **9.0.318**, `Godot.NET.Sdk/4.7.2`, target `net9.0`
- Godot-bundled NuGet packages, no third-party runtime dependency
- Headless **Dummy** audio driver with real Godot AudioServer mixing and generated PCM input

Earlier/later Godot versions and platform export targets are not claimed as tested. The runner accepts SDK/framework overrides for a project's matching Godot version.

## Reproducible commands

```bash
python3 tests/run_quick_audio.py --godot "$GODOT" --backend all
python3 tests/run_quick_audio.py --godot "$GODOT" --backend csharp
python3 tests/run_quick_audio.py --godot "$GODOT" --backend gds
```

Each command creates a temporary project containing only this addon, isolates editor/user data and build caches, and cleans up afterward. C# builds include both Debug and ExportRelease, with warnings treated as errors. Imports are checked for Godot error output even if the engine returns exit code zero.

## Coverage

- GDScript original runtime suite after migration: assets, defaults, ordered tracks, playback, voice limits, pause processing, controls, deterministic errors, ensure-playing, transactional invalid configuration, and Master lifecycle
- GDScript package suite: moved files/UIDs/public classes, paths, example loads, and plugin ownership/mutual-exclusion guards
- Combined C# runtime suite: **186 checks**; C#-only package skips GDScript-to-C# conversion checks
- C# resources and example scene load; typed asset/library ResourceSaver round trips; Inspector inherited properties
- Validation errors: null/empty library, null track, empty/duplicate IDs and bus names, reserved Master, bad voice count/process mode, missing parents and cycles
- Play/ensure/stop APIs, independent voices, oldest-voice replacement, deterministic error signals, stop callback reentrancy, callbacks that free players, reset/re-enter the manager or mutate the request resource, immediate stop during AudioStarted, externally freed players, missing buses, detached lifecycle and re-entry
- Stable configuration snapshots prevent mutable resources from creating an invalid voice loop
- Track/Master volume clamps, mute controls, actual SceneTree pause flags and process modes
- Created bus removal; reused bus send/volume/mute/order restoration; parent-first graph installation without changing public resource order or breaking existing unmanaged downstream sends; preserves effective Master fallback for formerly invalid forward sends and restores their original configuration
- Generated sine PCM plays through a real AudioStreamPlayer. AudioEffectCapture confirms **nonzero waveform data on the parent bus**; muting that parent confirms silence at the **Master mixer output**. Real natural `Finished` events clear the registry and release players
- Explicit GDScript resource conversion preserves IDs, stream/track references, volume and pitch, and saves/reloads as C# resources, including shared external track references
- Real editor lifecycle driver: **68 checks** across five separate editor processes. Both activation orders, conflicting sibling activation, foreign singleton/non-singleton ownership, replaced services, Inspector fields and save/reload, plus persistent UID Autoload ownership across actual GDScript and C# editor restarts
- All 8 existing GDScript script UIDs retained byte-for-byte; new script UIDs generated by Godot

This verifies playback state and generated mixer samples, not physical speakers, headphones, a listening session, or platform-specific audio drivers. No spatial/fade/settings-UI features existed in the source addon. Those are not added or claimed here.

## Runtime hardening boundaries

The GDScript runtime was preserved, with only its internal paths migrated. C# additionally snapshots configuration, establishes correct bus ordering, protects replacement callbacks, and cleans up configured nodes freed before entering the tree. These differences are documented in the C# README rather than silently changing the retained GDScript behavior.

## CI

The source `main` commit had no configured GitHub Actions workflow, and this audio branch does not add one. The separate Quick Input feature branch has its own unrelated workflow. The checked-in local runner is the executable validation record; no hosted CI success is implied by these local results.
